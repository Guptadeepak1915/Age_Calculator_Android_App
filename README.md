# 📱 Age Calculator App (Flutter)

A simple and elegant **Age Calculator mobile application** built using Flutter.
This app helps users quickly calculate their exact age based on their date of birth in a clear and accurate way.

---

## ✨ Overview

The Age Calculator App is designed with a minimal and user-friendly interface, making it easy for anyone to calculate their age within seconds.
It uses Flutter’s built-in date handling capabilities to provide precise results.

---

## 🚀 Features

* 📅 Easy Date of Birth selection using Date Picker
* 🧮 Instant age calculation
* 📊 Displays age in:

  * Years
  * Months
  * Days
* ⚠️ Input validation and error handling
* 🎨 Clean and responsive UI
* ⚡ Fast and lightweight performance

---

## 🛠️ Tech Stack

* **Framework:** Flutter
* **Language:** Dart
* **IDE:** Android Studio / VS Code
* **State Management:** setState

---

## ⚙️ How It Works

* The user selects their Date of Birth
* The app compares it with the current date
* It calculates the difference between both dates
* Finally, it displays the age in years, months, and days

The calculation logic ensures accurate results by considering real calendar differences.

---

## 📥 Installation Process

Follow these steps to run the project locally:

1. **Clone the repository**

```bash
git clone https://github.com/Guptadeepak1915/Age_Calculator_Android_App.git
```

2. **Navigate to project folder**

```bash
cd Age_Calculator_Android_App
```

3. **Get dependencies**

```bash
flutter pub get
```

4. **Run the app**

```bash
flutter run
```
